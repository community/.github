# GitHub Community

GitHub Community está diseñado para apoyar a todos los usuarios de GitHub en su **trayectoria educativa**, a través de **Discussions**.  
Es un **hub de recursos**, **portal de aprendizaje** e **inspiración**, todo en uno.  
Independientemente del tamaño de tu desafío, toda la información está disponible en un **formato open source**.

## ⚠️ Notas importantes

### Integraciones externas
> Por seguridad, las integraciones de terceros están **desactivadas temporalmente** debido a solicitudes sospechosas de miembros externos.

### Límites de interacción temporal
Para reducir el spam, se aplican **límites temporales** para cuentas con menos de 24 horas en el espacio `github.com/community` Discussions.  
Cuentas con al menos 24 horas podrán interactuar normalmente.  

Si tu cuenta es reciente y tienes preguntas, **usa el buscador de Discussions** o espera un día.  
Más información en la [documentación oficial](https://docs.github.com/en/communities/moderating-comments-and-conversations/limiting-interactions-in-your-organization).
